# 禅息 · ZenXi

一个安静的瑜伽 / 冥想计时器：**在设定时间的最后 4 秒，响起「叮 · 叮 · 叮 · 铛」**。

App 在后台也能稳定计时，提示音走**闹钟声道**——手机静音时依然会响，
你也可以一边放着视频、一边等铃声，提示音会叠在视频上，不会打断播放。

## 一、交付物

| 文件 | 说明 |
| --- | --- |
| `dist/ZenXi-v1.0.1.apk` | 可直接安装的安卓安装包（约 2.9 MB） |
| `app/` | 完整源码（Java + 原生 View，无第三方 SDK） |
| `tools/` | 铃声合成、图标生成、构建、测试脚本 |

安装：把 APK 传到手机 → 点击安装（首次需在系统设置里允许「安装未知应用」）。
支持 Android 7.0 及以上（minSdk 24），无原生库，所有 CPU 架构通用。

## 二、核心功能

**1. 末尾四声铃（核心）**

最后 4 秒，每秒一声：叮 · 叮 · 叮 · 铛。两种节奏可选：

- **连响**（默认）：`-4s 叮`、`-3s 叮`、`-2s 叮`、`-1s 铛`，最后一秒由「铛」的余韵盖住终点；
- **终点重音**：`-3s 叮`、`-2s 叮`、`-1s 叮`、`0s 铛`，「铛」正好落在结束的那一刻。

**2. 后台稳定运行**

- 前台服务 + `PARTIAL_WAKE_LOCK`，切到别的 App、锁屏、看视频都不会停；
- 提示音用 `USAGE_ALARM` 声道播放：静音模式依然响，且不会暂停你正在播放的视频；
- 通知栏显示**实时倒计时**，带「暂停 / 结束」快捷按钮；
- 进程被系统回收后会自动续跑剩余时间。

**3. 可开关的拓展功能**（设置里全部有开关）

| 功能 | 说明 |
| --- | --- |
| 准备倒计时 | 3 / 5 / 10 秒倒数（滴 · 滴 · 滴 · 起） |
| 收束长铃 | 结束后再落一记悠长的低音颂钵铃 |
| 半程轻铃 | 练习过半轻响一声（1.5 分钟以上） |
| 整分铃 | 长练习时，每隔 1 / 2 / 3 / 5 / 10 分钟的末尾再响一轮「叮 叮 叮 铛」 |
| 音色 | 铜铃 / 水晶 / 颂钵 / 木鱼 / 水滴（全部为程序合成音，无版权素材） |
| 起势音 | 准备结束、正式进入练习时的那一声：双铃 / 清铃 / 滑音 / 木鱼 / 水滴 / 静音 |
| 铃声音量 | 0–100% 可调，点一下即可试听 |
| 呼吸引导 | 4-4-4-4 / 4-7-8 / 5-5，配柔和进出声与呼吸光晕 |
| 连续练习 | 1–5 组，组间休息 15 / 30 / 60 秒 |
| 语音报时 | 开始 / 休息 / 结束用系统语音播报 |
| 震动同步 | 每一声铃同时轻震（铛更重） |
| 屏幕常亮 | 前台计时时不熄屏 |
| 素白模式 | 深色「禅夜」与浅色「素白」两套主题 |
| 练习记录 | 今日 / 本周 / 累计 / 连续天数 + 近七日柱状图 |
| 电池白名单 | 一键跳到系统设置，避免被国产 ROM 清理 |

## 三、界面与动效

- **计时圆环**：剩余时间的弧线（玉色 → 天青渐变）、弧线顶端的光点、缓慢呼吸的光晕；
  空闲时光点沿着圆环缓慢巡游。进入最后 4 秒，颜色渐变为暖琥珀色，每一声铃都会推出一圈脉冲。
- **氛围背景**：深墨渐变上两团缓慢漂移的光雾，计时进行中才流动，省电。
- **控件动效**：开始按钮淡出后，暂停 / 结束按钮以回弹曲线放大进入；
  胶囊选择片、开关、底部面板、记录柱状图都有各自的缓动动画。
- **完成浮层**：扩散环 + 回弹卡片，显示本次时长与连续天数，8 秒后自动淡出。

## 四、权限说明

| 权限 | 用途 |
| --- | --- |
| `POST_NOTIFICATIONS` | 显示后台倒计时通知（Android 13+ 需授权） |
| `FOREGROUND_SERVICE` / `..._MEDIA_PLAYBACK` | 后台计时服务 |
| `WAKE_LOCK` | 保证铃声准时（只在计时期间持有） |
| `VIBRATE` | 震动同步 |
| `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS` | 可选，加入电池白名单防误杀 |

App 不联网、不申请存储/通讯录/定位权限，练习记录只存在本机。

> 提示：在小米 / 华为 / OPPO / vivo 等系统上，建议把「禅息」加入
> **电池优化白名单 / 允许后台运行 / 允许自启动**，否则系统可能在锁屏后清理后台。

## 五、从源码构建

构建完全离线可用，只依赖 Android SDK 的 `build-tools 35` 与 `platforms;android-35`
（放在 `.toolchain/android-sdk` 下），流程为 aapt2 → javac → d8 → 打包 → zipalign → apksigner。

```powershell
# 1) 生成铃声与图标（Python + numpy + pillow）
python tools\gen_sounds.py
python tools\gen_icons.py

# 2) 跑时间线单元测试（纯 JVM，不需要手机）
powershell -ExecutionPolicy Bypass -File tools\test_timeline.ps1

# 3) 编译并签名出 APK
powershell -ExecutionPolicy Bypass -File tools\build.ps1

# 4) 静态自检 APK 结构
python tools\verify_apk.py dist\ZenXi-v1.0.1.apk
```

签名密钥在 `keystore/zenxi.jks`（口令 `zenxi2026`，仅供侧载使用；若要上架请换成自己的正式密钥）。

### 源码结构

```
app/java/com/zenxi/yogatimer/
  MainActivity.java     主界面与所有面板
  TimerEngine.java      计时引擎（前台服务 + 唤醒锁 + 定时出声）
  Timeline.java         练习时间线（纯 Java，可单测）
  TimerService.java     前台服务与倒计时通知
  SoundBank.java        铃音播放（闹钟声道）
  Speaker.java          系统语音播报
  Settings.java / Stats.java / Palette.java / Ui.java
  ui/                   自绘控件：计时圆环、氛围背景、开关、胶囊、柱状图、底部面板
```
